# 🌍 AI Language Translation Tool

## 📌 Description
This project is an AI-powered language translation tool built using Python and Gradio. It translates text between multiple languages using Google Translator API.

## 🚀 Features
- Translate text instantly
- Multiple language support
- Simple and interactive UI

## 🛠️ Technologies Used
- Python
- Gradio
- deep-translator
